# 🎄 Merry Christmas Web Page

An interactive, Christmas-themed web application featuring animated elements, falling snow, and a festive glassmorphism card design.

## Features

- **Falling Snow Animation:** Dynamic JavaScript-generated snowflakes falling across the screen.
- **Interactive Christmas Elements:** Glowing Christmas tree and bouncing snowmen animations using pure CSS.
- **Glassmorphism Design:** Modern card layout with blur effects and soft shadows.
- **Surprise Button:** Interactive alert feature for a festive greeting.

## Technologies Used

- **HTML5** - Page structure and semantic layout
- **CSS3** - Animations (`@keyframes`), Flexbox, Glassmorphic styling, and layout design
- **JavaScript (Vanilla)** - Dynamic snowflake generation and DOM manipulation
